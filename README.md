# Ironman Cascais 2027 — plano de preparação

Site de uma página (`index.html`) para planear a preparação para o Ironman Portugal Cascais 2027.

- Contagem decrescente até à prova (data provisória: 16 out 2027, ajustável)
- Periodização em 6 fases (Base 1, Base 2, Construção 1 e 2, Pico, Afinação) com semanas de recuperação
- Plano diário de cada semana com durações calculadas a partir das horas da semana de pico
- Registo de treinos com totais semanais vs. planeado
- Checklist de logística, material e saúde

`src/page.html` é a fonte; `index.html` é a mesma página com o esqueleto HTML, para abrir no navegador ou publicar no GitHub Pages.
Fora do claude.ai, os dados ficam guardados no navegador (localStorage).
